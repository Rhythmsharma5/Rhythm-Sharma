# JARVIS

A lightweight Jarvis-inspired personal assistant dashboard built as a static web app.

## Features

- AI-style command interface
- Voice activation support (browser speech recognition when available)
- Live system status panel
- Quick action buttons
- Local, dependency-free experience

## Run locally

Open `index.html` directly in the browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit: http://localhost:8000

## Files

- `index.html` — app layout
- `styles.css` — interface styling
- `script.js` — assistant logic and interactive commands
